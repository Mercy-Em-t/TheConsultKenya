# System Message Specification: MSG-CONFIRM-01
**Message Classification:** Confirmation Message

### When Displayed (Trigger)
User is about to execute an irreversible action (e.g., releasing escrow funds, cancelling a booking, deleting a case study).

### Visual Presentation & Styling
Centrally focused modal dialog with dark backdrop blur; clear typography; high-contrast action buttons.

### Canonical Copy & Text
> **"Are you sure you want to approve Milestone 2 and release KES 250,000? This action is legally binding and irreversible."**

### Dismissal & User Action Protocol
Requires explicit button click: Primary 'Yes, Authorize Release' (Green) or Secondary 'Cancel' (Neutral Gray).
