# System Message Specification: MSG-STATUS-01
**Message Classification:** Status / Informational Message

### When Displayed (Trigger)
User initiates case study drafting or asynchronous task (e.g. background save, vector re-indexing).

### Visual Presentation & Styling
Subtle non-blocking toast at bottom-right (Desktop) or top pill (Mobile); blue/neutral palette (#2563EB).

### Canonical Copy & Text
> **"Draft saved automatically. All diagrams and assets synced."**

### Dismissal & User Action Protocol
Auto-dismisses after 3 seconds; no user action required.
